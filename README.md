# 📡 PulseChurn — Interpretable Customer Churn System

An end-to-end machine learning pipeline designed to predict customer churn and mathematically explain the specific factors driving individual risk scores.

## ✨ Features

### 📥 Step 1 — Data Ingestion & Engineering

Formats raw data, handles initial cleanup, and prepares customer features for statistical modeling.

### ⚙️ Step 2 — Leakage-Resistant Preprocessing

Implements a strict 70/15/15 stratified split. Uses a `ColumnTransformer` to scale numeric features and one-hot encode categorical data, fitted exclusively on the training set to prevent data leakage.

### 🧠 Step 3 — Model Training & Evaluation

Trains a Logistic Regression classifier utilizing balanced class weights to mathematically handle the class imbalance inherent to churn data.

### 🔌 Step 4 — FastAPI Backend Prediction Service

Exposes a REST API that takes a Customer ID, transforms their raw data via the saved preprocessor, and calculates their churn probability and local log-odds contributions.

### 💻 Step 5 — Interactive UI / Dashboard

A decoupled React frontend that communicates with the FastAPI backend to visualize the prediction, confidence score, and local feature interpretability. A Streamlit dashboard is also provided as an alternative interface.

### 🧭 Global Navigation

Clean, user-friendly interface to quickly search records and interpret the underlying model mechanics.

## 🚀 Setup

### **1. Clone / Extract Project**

```bash
git clone https://github.com/Vaishnavi27072004/TelcoPulse.git
cd TelcoPulse
```

### **2. Create Virtual Environment**

```bash
python -m venv venv
```

Activate the virtual environment:

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### **3. Install Dependencies**

```bash
pip install -r requirements.txt
```

### **4. Add the Kaggle Dataset**

Download the **Telco Customer Churn** dataset from Kaggle and place the following CSV file inside the `data/raw/` directory:

```text
WA_Fn-UseC_-Telco-Customer-Churn.csv
```

The directory should look like:

```text
data/
└── raw/
    └── WA_Fn-UseC_-Telco-Customer-Churn.csv
```

### **5. Run the Project**

Execute the pipeline in this exact order:

```bash
python 1_load_real_data.py
python 2_prepare_sequences.py
python 3_train_model.py
python 4_backend_api.py
```

### **6. Launch the Dashboard**

After starting the backend API, open a new terminal and navigate to the frontend directory:

```bash
cd frontend
```
Install the frontend dependencies:

```bash
npm install
```
Start the React development server:

```bash
npm run dev
```
### **7. Alternative Streamlit Dashboard**

A Streamlit dashboard is also included as an alternative interface:

```bash
streamlit run 5_dashboard.py
```

## 🛠️ Key Design Decisions

### Model Choice

Logistic Regression was chosen over black-box models because its coefficients can be directly extracted and used for local interpretability.

### Decoupled Architecture

The ML backend is separated from the frontend UI using FastAPI, following a production-oriented enterprise architecture.

### Balanced Class Weights

Balanced class weights are used to reduce majority-class bias without artificially oversampling the dataset.

### Leakage-Resistant Preprocessing

All preprocessing transformations are fitted exclusively on the training data to prevent information leakage into validation and test sets.

---

## 📊 Model Interpretation

TelcoPulse provides not only a churn probability but also an explanation of **why a particular customer receives that risk score**.

The system calculates local feature contributions using the Logistic Regression coefficients and displays the factors that increase or decrease the customer's churn risk.

---

## 🎯 Project Objective

The primary objective of TelcoPulse is to build an **interpretable customer churn prediction system** that combines machine learning prediction with mathematical explanations, allowing businesses to understand the factors influencing individual customer churn risk.
